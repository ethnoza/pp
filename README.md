# Антиспам-бот для Telegram-группы

Удаляет сообщения, которые зазывают в другие группы и каналы:

- ссылки на чужие чаты: `t.me/...`, `t.me/+инвайт`, `t.me/joinchat/...`, `tg://join?...` — в тексте, в скрытых ссылках и в кнопках;
- упоминания `@username`, если это группа или канал, а не человек;
- фразы без ссылки: «переходите в другую группу», «подписывайтесь на канал», «группа переехала», «ссылка в профиле», `join our group` — в том числе с подменой букв на латиницу;
- (по желанию) пересылки из чужих каналов и групп.

Сообщения админов, анонимных админов и посты привязанного канала не трогает. Отредактированные сообщения тоже проверяются. Ссылки на саму группу разрешены.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Добавьте бота в группу и сделайте **администратором с правом «Удаление сообщений»**.
3. Запустите:

```bash
pip install -r requirements.txt
export BOT_TOKEN="123456:ABC..."
python bot.py
```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота (обязательно) |
| `ALLOWED_CHATS` | пусто | Юзернеймы через запятую, ссылки на которые разрешены: `mychannel,partner_chat` |
| `CHECK_PHRASES` | `1` | Удалять по фразам без ссылки. `0` — удалять только ссылки и упоминания |
| `DELETE_FORWARDS` | `0` | `1` — удалять пересылки из чужих каналов и групп |

Удалённые сообщения пишутся в лог с причиной. Фразы настраиваются в `spamfilter.py`.
