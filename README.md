# Антиспам-бот для Telegram-группы

Удаляет сообщения, которые зазывают в другие группы и каналы:

- ссылки на чужие чаты: `t.me/...`, `t.me/+инвайт`, `t.me/joinchat/...`, `tg://join?...` — в тексте, в скрытых ссылках и в кнопках;
- упоминания `@username`, если это группа или канал, а не человек;
- фразы без ссылки: «переходите в другую группу», «подписывайтесь на канал», «группа переехала», «ссылка в профиле», `join our group` — в том числе с подменой букв на латиницу;
- вызовы чужих ботов (`@SomeBot 4a55249b3d`) и ответы «гостевых» ботов — схема «Чат переносится в новую группу», см. ниже;
- (по желанию) пересылки из чужих каналов и групп.

Сообщения админов, анонимных админов и посты привязанного канала не трогает. Отредактированные сообщения тоже проверяются. Ссылки на саму группу разрешены.

## Атака «Чат переносится в новую группу»

1. Со взломанного аккаунта участника в группу уходит сообщение `@какой_то_bot 4a55249b3d`.
2. Это вызов бота в «гостевом режиме» (Bot API 10.0): бот не состоит в группе, но публикует ответ «от имени» участника — текст-ссылку «Чат переносится в новую группу. Нажмите на этот текст…».
3. Ссылка ведёт в бота, который под видом вступления выманивает номер и код входа. Аккаунт угоняют, и он рассылает то же самое дальше.
4. Исходное сообщение-вызов удаляется, аккаунт выходит из группы.

Бот удаляет сообщение-вызов, ответ гостевого бота (если Telegram его доставляет) и по умолчанию запрещает писать вызвавшему аккаунту — для этого нужно право «Блокировка пользователей». После восстановления аккаунта ограничение снимается вручную.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Добавьте бота в группу и сделайте **администратором с правами «Удаление сообщений» и «Блокировка пользователей»**.
3. Запустите:

```bash
pip install -r requirements.txt
export BOT_TOKEN="123456:ABC..."
python bot.py
```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота (обязательно) |
| `ALLOWED_CHATS` | пусто | Юзернеймы через запятую, ссылки на которые разрешены: `mychannel,partner_chat` |
| `CHECK_PHRASES` | `1` | Удалять по фразам без ссылки. `0` — удалять только ссылки и упоминания |
| `ON_BOT_CALL` | `mute` | Что делать с автором сообщения-вызова `@SomeBot код`: `mute` — запретить писать, `ban` — забанить, `delete` — только удалить |
| `DELETE_FORWARDS` | `0` | `1` — удалять пересылки из чужих каналов и групп |

Удалённые сообщения пишутся в лог с причиной. Фразы настраиваются в `spamfilter.py`.
